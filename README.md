## Key Features & Modules

1. **Cyber Command-Center UI**: Premium deep-charcoal theme with metallic gold and amber glow accents.
2. **Cybercrime Intelligence Dashboard**: Visualizes official data published by the National Crime Records Bureau (NCRB) and I4C with full source citations.
3. **Banking Fraud Analytics**: Explains the RBI commercial bank fraud paradox (Volume vs. Value breakdown).
4. **UPI Safety Academy**: Comprehensive guidance on QR-code scams, collect requests, remote-access APKs (AnyDesk/TeamViewer), and the RBI limited liability circular.
5. **Historical Evolution Timeline**: Trace fraud detection from 1950s manual carbon paper to 2020s behavioral graph AI.
6. **Empirical Case Studies**: Analyzes the Yapı Kredi & FICO real-time fraud scoring deployment with explicit vendor-reported caveats.
7. **ML Fraud Detection Simulator**: Interactive feature testing with explainable SHAP-style reason codes and the illustrative **₹78,000 Tirupati rapid-burst teaching scenario**.
8. **Financial Time-Series Forecasting**: Extrapolates digital payment throughput trends with 95% confidence intervals and regression error metrics (MAE, RMSE, MAPE).
9. **RAG-Grounded AI Assistant**: Safety advisor strictly enforcing zero credential collection (anti-OTP/PIN protection) and direct 1930 emergency referral.
10. **Community Reporting Portal**: Secure reporting of scam modalities with client/server PII sanitization.
11. **Host Super Admin Panel**: Server-enforced role management, telemetry monitoring, and immutable audit logging.

## Quick Start (Local Setup)

### 1. One-Click Launcher (Windows)
Double-click `start-dev.bat` or run:
```powershell
.\start-dev.ps1
```

### 2. Manual Setup

#### Backend Setup
```bash
cd backend
python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On Linux/macOS:
# source .venv/bin/activate

pip install -r requirements.txt
python run.py
```
Backend will start on: **http://127.0.0.1:8000** (Swagger API Docs at `/docs`).

#### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Frontend will open on: **http://localhost:5173**.
